# 道韵乾坤 · 3D 五行八卦罗盘

一个用 WebGL 实时渲染的堪舆罗盘。六层同心盘面、可展开的浑天仪、程序化生成的盘面铭文，配上实时合成的颂钵与铜铃。

**[在线体验 →](https://alinger.github.io/dao-pro/)**

---

## 这是什么

传统风水罗盘（罗经）是层层套叠的同心圆盘，每一层承载一套独立的方位或星象体系 —— 二十四山、二十四节气、二十八宿、八卦、五行各占一环。

这个项目把它搬进浏览器：盘面是真的 3D 几何体，可以拨动、可以展开成浑天仪、可以逐层透视。所有铭文由 Canvas 程序化绘制后烘焙成 2048×2048 贴图，因此任意缩放下都很锐利；切换视角时贴图会重新烘焙，把无关的环压暗、目标环点亮。

## 盘面六环

从内到外，六道同心铜环：

| # | 环名 | 内容 | 数量 |
|---|---|---|---|
| 1 | 先天八卦天运环 | 乾坤震巽坎离艮兑，含三爻卦象 | 8 卦 |
| 2 | 五行生克环 | 木火土金水，含方位与季令 | 5 行 |
| 3 | 道历二十四节气天环 | 立春至大寒，按四季着色 | 24 节气 |
| 4 | 二十四山神位天环 | 子丑寅卯…壬癸，每山 15° | 24 山 |
| 5 | 二十八宿四象天纬环 | 角亢氐房心尾箕… | 28 宿 |
| 6 | 周天赤道道历天铭环 | 360° 刻度 + 道历纪年铭文 | 360° |

中心为天池太极盘与磁针。

## 六种视角

顶栏「视角菜单」一键切换，每种模式对应不同的镜头语言与图层：

| 模式 | 镜头 | 盘面表现 |
|---|---|---|
| **天元总览** | 近正俯视，盘面呈正圆 | 完整盘面，铜环隐藏 |
| **浑天演象** | 拉远压低，接近平视 | 六环撑开成浑天仪球体 |
| **五行生克** | 东侧斜俯视 41° | 五行环 + 节气环点亮，其余压暗 |
| **八卦推演** | 反向偏西、更低更近 | 内圈八卦环点亮，其余压暗 |
| **分层透视** | 俯平之间，保留层叠厚度 | 六环全部保留，轻度聚焦 |
| **阴阳吐纳** | 贴近盘面正俯视 | 呼吸引导浮层 + 低频底噪 |

在「五行生克」下点选某个五行，「八卦推演」下点选某一卦，盘面会**只保留该元素/该卦**，其余直接隐去 —— 让抽象的「生克」变成盘面上看得见的变化。

## 功能

**操盘交互**
- 拖拽拨盘（默认）或拖拽转视角（可切换），右键 / Shift 拖拽临时反转
- 单齿微调：每次 1°，等同机械罗盘的「一拨一齿」
- 自动旋转三档调速（悠缓 0.25× / 沉稳 1.0× / 灵动 3.0×），基准 1°/秒
- 盘面文字镜像（模拟罗盘背面读数，HUD 读数不翻转）

**读数与感知**
- 实时方位读数：物理角度、二十四山、阴阳属性、所属五行、对应卦象
- 气场仪：随转速变化的能量指示，自转时显示「活跃充盈」
- 道历徽章：当前节气与道历纪年

**典籍与音声**
- 道韵考据：二十四山各有一篇（古诗引文、典籍出处、天象渊源、风水意涵、修养之德）；亦可联网检索（Gemini + Google Search，需服务端）
- 使用手册：内置操作说明
- 全部音效由 Web Audio **实时合成**，无任何音频文件 —— 颂钵、铜铃、五行磬、旋转共振、吐纳底噪

## 技术栈

| 层 | 选型 |
|---|---|
| 框架 | React 19 + TypeScript |
| 3D | Three.js（直接操作场景图，未用 R3F） |
| 构建 | Vite 8（Rolldown） |
| 样式 | Tailwind CSS 4 |
| 动画 | Motion |
| 图标 | lucide-react |
| 服务端 | Express + @google/genai（可选，仅「联网考据」需要） |
| 包管理 | Bun |
| 部署 | GitHub Pages（GitHub Actions 自动构建） |

几个实现要点：

- **盘面是烘焙出来的，不是画上去的。** `textureGenerator.ts` 在 Canvas 上逐环绘制文字与色块，输出 2048² 贴图。视角切换时重烘焙并用 `source-atop` 压暗非目标环（用 `destination-out` 会挖出透明、透出盘底棕色形成刺眼异色环）。
- **盘面与铜环解耦。** 铜环的几何边界与贴图的内容边界天然对不齐，早期让铜环直接承载贴图会把内容环从中间切断。现在改由独立圆盘承载贴图、铜环退化为纯装饰，展开成浑天仪时整组隐藏即可。
- **音效全部合成。** 没有一个音频文件，颂钵与铜铃由振荡器 + 卷积混响实时生成，随转盘角速度调制。

## 快速开始

需要 **Bun**（推荐）或 Node.js 20.19+（Vite 8 的最低要求）。

```bash
git clone https://github.com/alinger/dao-pro.git
cd dao-pro
bun install
bun run dev          # → http://localhost:3000
```

`bun run dev` 启动的是 Express + Vite 中间件，前后端一起跑（「联网考据」也可用）。

### 可选：启用联网考据

不配也能用 —— 没有密钥时会返回内置的离线文案。

```bash
cp .env.example .env
# 填入 GEMINI_API_KEY
```

### 常用命令

| 命令 | 作用 |
|---|---|
| `bun run dev` | 开发服务器（Express + Vite，含 API） |
| `bun run build` | 生产构建 → `dist/` |
| `bun run preview` | 预览构建产物 |
| `bun run lint` | TypeScript 类型检查 |
| `bun start` | 生产模式运行 `server.ts`（需先 build） |

## 部署

推送到 `main` 自动触发 GitHub Actions：Bun 安装依赖 → 构建 → 发布到 Pages。

工作流见 [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml)。

两个容易踩的点已处理好：

- **子路径基准**：Pages 项目站点跑在 `/dao-pro/` 下，构建时通过 `VITE_BASE` 注入 `base`，否则 `/assets/*.js` 会全部 404。
- **锁文件**：CI 用 `bun install --frozen-lockfile`，锁文件与 `package.json` 不一致会直接失败（这是有意的，保证构建可复现）。

## 考据原则

盘面数据不是随意摆放的，几处关键对齐：

- **五行环的角度由二十四山反推**，不是五等分。水居正北（子）、木居正东（卯）、火居正南（午）、金居正西（酉）、土布四隅 —— 与二十四山、八卦方位三者互相吻合。
- **八卦环用后天（文王）方位**，坎 0°、艮 45°、巽 135°、离 180°、坤 225°、兑 270°、乾 315°，与二十四山的卦山逐一对应。
- **子山朝上、面南背北**：默认视角下子（北）落在屏幕正上方。

## 已知限制

- **「联网考据」在 GitHub Pages 上不可用。** Pages 是纯静态托管，没有 Node 后端，`POST /api/search-wisdom` 会 404。客户端做了降级，会显示离线文案，功能不会崩，但拿不到 Gemini 联网结果。要用这个功能，需要把 `server.ts` 部署到支持 Node 的平台。
- 首屏 JS 约 957 KB（gzip 257 KB），主要是 Three.js。尚未做代码分割。
- 触屏手势仅支持单指拖拽，未做双指缩放。
