## 正文内容

不是风水测算 App，也不是手机指南针。

我做的是一个能「拨」的 3D 罗盘 —— 六层同心圆盘，每一层都是一套独立的方位体系。

🧭 **六层是真的分开的**
先天八卦 → 五行生克 → 二十四节气 → 二十四山 → 二十八宿 → 周天三百六十度。
从里到外，一层一套说法，全部叠在一起，才是完整的罗经。

⚙️ **能拆开**
点一下，六道铜环会撑开成浑天仪，可以绕着看。盘面变成球体的那一秒，我自己看了很多遍。

✨ **视角会挑重点**
切到五行模式，五行环亮起来、其余自动压暗；在里面点「火」，盘面就只剩火的那一段。抽象的「生克」，变成盘面上看得见的变化。

📖 **每座山都有一篇**
二十四山，一山一篇典故：古诗引文、典籍出处、天象渊源、风水意涵。不是糊弄人的吉凶断语，是真能读的东西。

🔊 **有声音**
颂钵、铜铃、五行磬，全部实时合成，没有一个音频文件。盘转得快，铃声也跟着变。

一个细节：五行环的角度不是五等分，是按二十四山反推的 —— 水居正北、木居正东、火居正南、金居正西、土布四隅。懂的人会看出这一点。

不用装 App，浏览器打开就能玩，手机电脑都行。

链接放评论区了 👇 你觉得这六层里，哪一层最难做？

本次**未做数据库爆款分析** —— 小红书技能依赖的 `REDFOX_API_KEY` 未配置，拿不到 2000+ 爆款笔记数据。以下是基于平台通用规律 + 竞品扫描得出的公式，不是数据结论，如实标注。

采用的公式：**身份反差开场 + 分点亮点（每点都有可验证的具体细节）+ 技术彩蛋 + 评论区提问收尾**

- **分点结构**：5 个点，每点一个小标题 + 一句展开。小红书长文在移动端靠小标题撑可读性。
- **可验证细节**：不写"很震撼""很精美"这类空词，改写具体事实（六层名称、"没有一个音频文件"、水居正北）。具体信息本身就是可信度。
- **彩蛋段**：五行环角度那段，是给"懂的人"的钩子 —— 这类内容最容易激发评论（行家来纠错或认同）。
